The module covers HTTP and browser architecture; web programming principles and standards; development tools; prototyping; HTML and CSS; JavaScript and DOM manipulation; server-side development; frameworks; debugging; web testing; cross-platform compatibility; and AI-assisted development.

The author's planned AWS hosting and guestbook architecture are project decisions. They must not be described as technologies mandated by this syllabus.
